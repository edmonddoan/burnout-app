# Burnout App

An app for people running on empty — daily burnout check-ins, energy and stress trends, and recovery planning.

**Stack:** Spring Boot (REST API, JWT auth, PostgreSQL) + React + TypeScript frontend.

**Status:** Scaffolding. Backend lands in week 3, frontend in week 4 of the prep plan.

## Why this project

Built to prove end-to-end ownership: API design, auth, data modeling, charts, and a real UI — the exact shape full-stack roles hire for. And it's personal: built during a job hunt, for the stress that comes with it.
